# 常用软件

## 开源软件

| 软件 | 描述 |
| --- | --- |
| [Yaak](https://github.com/mountain-loop/yaak) | 跨平台类似于Postman的客户端 |
| [FLClash](https://github.com/chen08209/FlClash) | 跨平台Clash的代理客户端 |
| [LocalSend](https://github.com/localsend/localsend) | 跨平台文件传输工具 |
| [Sageport](https://github.com/joygqz/sageport) | 跨平台SSH管理工具 |
| [Zed](https://github.com/zed-industries/zed) | 跨平台IDE |
| [Easydict](https://github.com/tisfeng/Easydict) | MacOS翻译工具 |
| [Pearcleaner](https://github.com/alienator88/pearcleaner) | MacOS清理工具 |
| [Ghostty](https://github.com/ghostty-org/ghostty) | MacOS终端模拟器 |
